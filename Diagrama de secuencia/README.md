# Diagras de secuencia

Los diagramas de secuencia son una versión parecida al diagrama de interacción que se hizo para ISW I. Pero en este caso siguiendo la forma en que se "enseñó" (importante las comillas) en FAGO (o GPN no me acuerdo).

Ya está implementado el CU #1 que es el extremo de sencillo, y el CU #4 que ex uno de los más complejos, se utilizará esto como guía de estilo, es importante mantener la coherencia, por eso se deben seguir estas normas:

1. Nombrar funciones de forma igual entre diagramas (no tener CrearEvento() y CreateEvent()).
2. Mantener el diseño limpio y sin lineas entrecruzadas.
3. Crear un diagrama por cada sub proceso (casi que debe existir un diagrama por cada Requisito Funcional).

Utilizar los estereotipos que están en el directorio `templates/estereotipos/`, y la plantilla `templates/Template.excalidraw` para el diseño de los diagramas.

Este README es una continuación del que está en la raíz del repositorio, es importante leer ambos.
