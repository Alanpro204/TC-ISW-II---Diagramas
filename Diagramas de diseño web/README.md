# Diagramas de diseño web

En este directorio se trabajarán los diagramas de diseño en lenguaje UML con estereotipos de la web (casi sueno como Yadira aquí). Ya están hechos dos de los casos de uso (`CU #1.excalidraw` y `CU #4.excalidraw`), se va a seguir el estilo de estos diagramas, en el directorio `templates/estereotipos` están los estereotipos de la web que se utilizarán en los diagramas.

Para asegurarse de que los diagramas están correctos, se deberá seguir las siguientes normas:

1. Nombrar entidades del diagrama de manera igual entre diagramas (no tener `cp_crear_evento` y `cp_create_event`).
2. Mantener el diseño limpio y sin líneas cruzadas.
3. Crear un diagrama por cada Caso de Uso.

Este README es una continuación del que está en la raíz del repositorio, es importante leer ambos.
